The package ships a PHPStan extension, `extension.neon`. It is included automatically by
`phpstan/extension-installer`; otherwise include it by hand:

```yaml [phpstan.neon]
includes:
    - vendor/ark4ne/laravel-api-revisions/extension.neon
```

It types:

- `Route::revisioned()`;
- `assertMatchesRevisionSchema()` on a `TestResponse`;
- your [custom types](/laravel-api-revisions/extending/custom-types), called on `Schema`;
- your [descriptor macros](/laravel-api-revisions/extending/descriptor-macros), called on any descriptor.

## Map your types and macros

PHPStan cannot see what is registered at boot. Map each name:

```yaml [phpstan.neon]
parameters:
    apiRevisions:
        types:
            money: App\Schema\MoneySchema
        macros:
            whenInFields: 'App\Schema\FieldMacros::whenInFields'
```

- `Schema::money(...)` then takes the parameters of `MoneySchema`'s constructor and returns a `MoneySchema`.
- `->whenInFields(...)` takes the parameters of the method after the descriptor, and returns the type it is called on:
  `Schema::string()->whenInFields('notes')` is a `StringSchema`.

## Retiring a revision

When you delete a case from the enum, PHPStan reports every reference left to it: the `since()`, `until()` and
`was()` that [`revision:prune`](/laravel-api-revisions/evolving-the-api/retiring-a-revision) listed, and any guard on it.
