title: Configuration

Publish the file with `php artisan vendor:publish --tag=revisions-config`. `Ark4ne\ApiRevisions\Laravel\RevisionsConfig`
is the validated configuration, a singleton: an invalid value throws a `ConfigurationException`.

## Revisions

::field-group
:::field{name="enum" type="class-string|null"}
Your revision enum: a backed enum implementing `Revisions\Revision`. Default `null`: the library works on one implicit
revision, `head` (`Revisions\Unrevisioned`), with no history, no revision header and nothing locked.
:::
:::field{name="default" type="string|class-string"}
The revision when no resolver answers: `latest` (the head), `oldest`, a backed value of the enum, or a resolver
class. Outside a request (jobs, console), a fixed revision is the current one; a resolver class gives the head.
Without enum, only `latest` or `oldest`. Default `'latest'`.
:::
::

## Resolution

::field-group
:::field{name="resolvers" type="array<class-string, array>"}
The chain of resolvers, `class => options` (named constructor arguments), or the class alone. The first one
returning a revision wins. Default: `HeaderResolver::class => ['name' => 'Api-Revision']`. See
[Resolving the revision](/laravel-api-revisions/revisions/resolving-the-revision).
:::
:::field{name="response_header" type="string"}
The response header naming the revision a response was rendered in. Default `'Api-Revision'`.
:::
::

## Values

::field-group
:::field{name="missing_default" type="'error'|'null'"}
What a `required()->since(R)` field declared without `default:` gives clients older than `R`: `'error'` (nothing,
reported by `revision:check` as `required-since-without-default`) or `'null'`. Default `'error'`.
:::
:::field{name="strict_values" type="bool|null"}
Value errors (a value its type refuses, a failed conversion, a `null` on a non-nullable field) are thrown as
`ValueException` (`true`), or cast and reported once per class and field (`false`). Default `null`: follows
`app.debug`.
:::
:::field{name="date_format" type="string"}
The format of `Schema::date()` without `format()`. Default `'Y-m-d'`.
:::
:::field{name="date_time_format" type="string"}
The format of `Schema::dateTime()` without `format()`. Default `'Y-m-d\TH:i:sP'`.
:::
::

## Tooling

::field-group
:::field{name="discovery.paths" type="string[]"}
The directories scanned for classes implementing `Revisioned`, by `revision:check`, `revision:cache` and the other
commands. Default `[app_path()]`.
:::
:::field{name="discovery.classes" type="class-string[]"}
Classes outside those paths (packages, modules). Default `[]`.
:::
:::field{name="cache_path" type="string"}
The compiled shapes written by `revision:cache`. Default `base_path('bootstrap/cache/revisions.php')`.
:::
:::field{name="lock_path" type="string"}
The directory of the lock files, one per revision: commit it. Default `base_path('revisions.lock')`.
:::
::
