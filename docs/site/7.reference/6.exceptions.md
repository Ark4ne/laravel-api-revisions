---
title: Exceptions
description: Every exception the package throws, and when.
---

Every exception implements `Ark4ne\ApiRevisions\Exceptions\RevisionsException`, in the namespace
`Ark4ne\ApiRevisions\Exceptions\`.

| Exception | Thrown on |
| --- | --- |
| `DefinitionException` | a programming error in a declaration; the check reports it as `definition-error` |
| `ConfigurationException` | an invalid `config/revisions.php`, or a tagged check that is not a `Check` |
| `UnknownRevisionException` | a revision the API does not know; the middleware answers it **400** |
| `ValueException` | a value the rendering cannot produce, when `strict_values` is on |
| `ConversionException` | a value a conversion cannot convert; in a request, a validation error on the client's key |
| `InvalidInputException` | an input the upgrade rejects, rendered as a validation error |
| `LockException` | a lock file that cannot be read or written |
| `CacheException` | the compiled shapes file that cannot be read or written |
