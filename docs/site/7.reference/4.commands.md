---
title: Commands
description: Every Artisan command of the package and its options.
---

| Command | Role |
| --- | --- |
| `revision:check` | checks every discovered class; exits `1` on an error |
| `revision:lock` | locks the published revisions |
| `revision:export` | the JSON Schema of every class, kind and revision |
| `revision:changelog` | the changelog of the revisions, in Markdown |
| `revision:prune` | the declarations the oldest revision alone uses |
| `revision:cache` | compiles every shape to `cache_path` |
| `revision:clear` | deletes the compiled shapes |

## revision:check

::field-group
:::field{name="--format" type="table|json"}
The output. Default `table`. See [Check](/laravel-api-revisions/tooling/check).
:::
:::field{name="--list" type="flag"}
Prints the discovered classes only, without checking.
:::
::

## revision:lock

::field-group
:::field{name="--revision" type="string"}
(Re)locks one revision, by its backed value, the head included. Without it, locks every revision but the head that has
no lock yet. See [Lock](/laravel-api-revisions/tooling/lock).
:::
::

## revision:export

::field-group
:::field{name="--revision" type="string"}
Keeps one revision, by its backed value.
:::
:::field{name="--class" type="string"}
Keeps one class. With one revision, one class and one kind left, prints a single schema.
:::
::

## revision:changelog

::field-group
:::field{name="--from" type="string"}
The revision to start after (excluded).
:::
:::field{name="--to" type="string"}
The last revision listed (included).
:::
::

Newest revision first.

## revision:prune

No option. Lists, with file and line, each `until()`, `was()` and `since()` naming the oldest revision. Always
succeeds. See [Retiring a revision](/laravel-api-revisions/evolving-the-api/retiring-a-revision).

## revision:cache, revision:clear

No option. `php artisan optimize` runs `revision:cache` and `optimize:clear` runs `revision:clear`. See
[Performance and Octane](/laravel-api-revisions/tooling/performance-and-octane).
